Workflow Stages

Five agents coordinate to recommend an action.

1. Diagnosis Agent

Classifies the issue and reports prediction confidence for information only. This score does not independently trigger escalation.

2. Retrieval Agent

Searches the knowledge base for relevant operational evidence.

3. Resolution Agent

Prepares a response using relevant retrieved knowledge.

4. Validation Agent

Checks confidence, evidence, and escalation requirements.

5. Action Agent

Recommends whether to continue or escalate to human support.
